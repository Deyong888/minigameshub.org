## How to Get Unblocked Games Working on a School Chromebook

A few practical notes that save people a lot of frustration:

**Use a fresh tab, not a bookmarked one.** School filters often cache the block page. Opening a game in a brand-new incognito-style tab frequently gets you a clean request.

**Disable hardware acceleration if games stutter.** On low-RAM Chromebooks, turning hardware acceleration *off* in browser settings sometimes fixes frame drops in WebGL titles like Drift Hunters.

**Close the other twelve tabs.** Seriously. Four gigabytes of RAM disappears fast, and a browser game that's fighting for memory will feel broken when it isn't.

**Mute first.** Most browser games start with audio enabled. Find the speaker icon in the frame before you start playing, not after.

**Prefer single-player offline titles during class.** Anything on the table above marked "No" for internet is rendered locally after the page loads, which means it keeps working even if the connection drops out mid-session.
